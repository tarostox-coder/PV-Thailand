# PV Dashboard — Change Logger (Apps Script)

ฟีเจอร์ **"ใครแก้ · อะไร · เมื่อไหร่"** ของ Dashboard ทำงาน 2 ชั้น:

| ชั้น | ตอบคำถาม | ต้องติดตั้งอะไร | ขอบเขต |
|------|----------|----------------|--------|
| **Diff ฝั่ง Dashboard** (มีให้อัตโนมัติ) | *อะไร* เปลี่ยน — โครงการไหน · คอลัมน์ไหน · ค่าเก่า→ค่าใหม่ | ไม่ต้องตั้งค่า | เทียบข้อมูลแต่ละรอบ sync |
| **Apps Script** (ไฟล์นี้) | เติม *ใคร* เป็นคนแก้ (อีเมล/ชื่อ) | ติดตั้งครั้งเดียวในชีต | onEdit ทุกการแก้ |

ดูแท็บ **📝 Activity** ใน Dashboard เพื่อดูบันทึกทั้งหมด

---

## วิธีติดตั้ง (ทำครั้งเดียว ~2 นาที)

1. เปิด **Google Sheet** ของโครงการ
2. เมนู **Extensions → Apps Script**
3. ลบโค้ดเดิมทั้งหมด แล้ววางเนื้อหาทั้งหมดของไฟล์ [`PV-ChangeLog.gs`](./PV-ChangeLog.gs) → กด 💾 **Save**
4. เลือกฟังก์ชัน **`setup`** ที่แถบด้านบน → กด ▶ **Run**
5. ครั้งแรกจะขอสิทธิ์: **Review permissions → เลือกบัญชี → Advanced → Allow**
6. เสร็จ ✓ — จะมีแท็บใหม่ชื่อ **`ChangeLog`** (ถูกซ่อนไว้) คอยบันทึกทุกการแก้

Dashboard จะอ่านแท็บ `ChangeLog` ผ่านลิงก์สาธารณะของชีตที่แชร์ไว้แล้ว (`Anyone with link = Viewer`) — **ไม่ต้องใส่ API key ใด ๆ**

---

## ข้อจำกัดเรื่อง "ชื่อผู้แก้"

- ✅ ผู้แก้ที่อยู่ใน **Google Workspace องค์กรเดียวกัน** กับเจ้าของชีต → ได้อีเมลผู้แก้ครบ
- ⚠️ ผู้แก้ที่เป็น **Gmail ส่วนตัว / คนนอกองค์กร** → Google อาจไม่เปิดเผยอีเมลด้วยเหตุผลความเป็นส่วนตัว ช่อง "ใครแก้" จะขึ้น `(unknown)` แต่ส่วน "อะไรเปลี่ยน" ยังบันทึกครบทุกครั้ง

> หมายเหตุ: `Old` (ค่าเดิม) จะบันทึกได้เฉพาะการแก้ทีละช่อง — การวาง/แก้หลายช่องพร้อมกัน Google จะให้เฉพาะค่าใหม่ ส่วนค่าเดิมฝั่ง Dashboard จะเติมให้จากการ diff แทน
